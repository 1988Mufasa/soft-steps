# Soft Steps — launch QA checklist

Run on a real **iPhone** and **Android** device before TestFlight / Play Internal.

## Install & shell
- [ ] Add to Home Screen (iOS Share → Add to Home Screen; Android Install / A2HS)
- [ ] Open from home icon (standalone), not the browser tab
- [ ] Splash / icon look correct
- [ ] Install banner camera/mic checklist → allow permissions

## Security
- [ ] First Grown-ups unlock with `1234` forces **Set your PIN** before other tools
- [ ] New PIN cannot be `1234`; confirm must match
- [ ] Wrong PIN 5× locks out; refresh does not clear lockout
- [ ] Idle ~5 min on Grown-ups → redirected to PIN gate
- [ ] Routine builder requires PIN (no math/hold shortcut)

## Core kid path
- [ ] Today’s path: First / Then → practice → Calm
- [ ] Weekly theme banner links work (foods kind / story / videos)
- [ ] Quiet calm / Meltdown Mode opens
- [ ] Quiet mode (Grown-ups) mutes celebrations + softens motion/colors

## Photos & storage
- [ ] Story photo, AAC photo, routine step photo — camera or library
- [ ] Oversized photos resize or show a clear error (no crash)
- [ ] Encrypted backup download + restore with PIN
- [ ] Restore keeps current device PIN

## Videos & network
- [ ] Offline topic lessons play without Wi‑Fi
- [ ] Family YouTube Kids embed plays on Wi‑Fi (or “Open in YouTube Kids” works)
- [ ] Purchase flow refuses offline; online opens Stripe (or demo message)

## Profiles & content
- [ ] Add sibling profile; progress stays separate
- [ ] Sign language shows ASL‑inspired disclaimer
- [ ] Caregiver onboarding banner dismisses once

## Store copy
- [ ] Privacy page `/privacy` readable; public HTTPS privacy URL ready for listing
- [ ] Age rating / permission strings match camera + mic use
