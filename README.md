# Soft Steps

Calm ABC, shapes, colors, and numbers practice for kids ages 3–12 (autism-friendly UX).

## Run locally

```bash
npm install
npm run dev
```

Production preview:

```bash
npm run build
npm run preview
```

## Default parent PIN

`1234`

## Offline vs online

- **Offline**: ABCs, Shapes, Colors, Numbers — fully usable after first load (PWA / service worker).
- **Online**: Bonus practice, demo progress sync, optional CDN narration notes.

## Stack

React + Vite + TypeScript + vite-plugin-pwa
